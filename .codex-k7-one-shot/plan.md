# K7 레이더 후보 일회성 시험 계획

1. 기존 정확한 K7 펌웨어 확인과 원본 설정 백업을 재사용한다.
2. 후보 하나를 쓴 뒤 같은 진단 작업에서 원본 설정을 복원하고 재읽는다.
3. 실패·복원 불명 경로의 테스트를 통과하기 전에는 자동 부팅 실행을 연결하지 않는다.

## 다음 차량 방문용 실행 경로

1. 6999 터미널에서 명시적으로 시작하는 정차 후보 시험을 추가한다.
2. 기존 별도 systemd 작업에서 K7 펌웨어와 현재값을 확인하고 후보 하나를 시험한다.
3. 본 시험이 중단돼도 별도 복원 확인 작업을 수행하고 결과 둘 다 업로드한다.
4. 보안·조건·통신 실패는 다음 후보로 자동 진행하지 않는다. 값 거절만 다음 후보 조사 근거로 분류한다.
