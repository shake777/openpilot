# K7 레이더 후보 시험 결정 기록

- 2026-09-23 현재 6999 주차 프로브는 읽기 전용이다.
- 현재 K7 실측 DID 0142는 0002000000이며 0002000001은 미검증 후보이다.
- 현재 수동 실험 경로는 쓰기 성공 뒤 후보값을 유지하므로 자동 시동 실행에 연결하지 않는다.
- 원본 복원 재읽기 성공은 트랙 활성화 증거가 아니다. 실제 트랙 관측은 별도 검증이다.
- 일회성 `--k7-test-write-restore` 옵션을 추가했다. 자동 부팅이나 6999 버튼에는 연결하지 않았다.
- 테스트는 후보 수락·거절·무시와 복원 실패를 확인한다. 실차 결과는 아직 없다.
- 다음 차량 방문에서는 6999 터미널의 명시적 실행을 사용한다. 시동마다 무인 자동 쓰기는 연결하지 않는다.
- 후보 결과와 독립 복원 결과는 기존 `k7-security-probe-*.json` 업로드 규칙으로 각각 전송한다.
- NRC `0x31`은 값 오류와 DID 쓰기 불가를 구분할 수 없어 모호한 거절로 분류한다. 보안·조건 거절도 값 판정으로 사용하지 않는다. 첫 실차 결과 전에는 다음 후보를 자동 선택하지 않는다.
- Windows에서 관련 32개 테스트와 AST 문법 검사는 통과했다. 전체 C4 테스트 발견 실행의 단일 실패는 Windows에 `capnp` 모듈이 없어 `test_inventory_transport`를 가져오지 못한 환경 제한이다.
