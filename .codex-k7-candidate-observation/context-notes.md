# 컨텍스트 노트

- 2026-09-25. 이번 세션 비교는 읽기 전용이며 후보 쓰기는 아직 실행되지 않았다. 따라서 다음 임의 값을 고르지 않고 기존 첫 후보의 관측력을 보강한다.

- 기존 자동 업로더는 `k7-security-probe-*.json`을 수집한다. 후보 시험 보고서와 상태 요약에 관측 통계가 실리며, 실차 업로드 성공은 업데이트 후 별도 확인한다.
