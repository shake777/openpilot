# K7 첫 후보 정차 관측 계획

기존 단일 후보 0002000001의 쓰기·원복 순서는 바꾸지 않는다. 후보 적용 전, 적용 직후, 원복 후 짧은 수동 CAN 수신 집계를 전체 보고서에 기록해 다음 업로드에서 트랙 범위의 변화를 비교한다.

검증은 후보 수락·거절·원복 실패의 모의 테스트, Python 문법 검사, 실제 Git 원격 커밋 확인으로 한다. 차량에서의 결과와 서버 접수는 이번 로컬 변경으로 입증되지 않는다.

## 2026-09-25 후속 단계

서버에 접수된 후보 시험은 DID 0x0142 쓰기에서 NRC 0x33을 반환해 후보가 적용되지 않았다. 같은 날 시험 전 원본 CAN은 버스 0·2에 0x500~0x53f 프레임이 있으나 버스 1 후보는 없었다. 다음 진단 보고서에는 프레임 수와 함께 버스별 길이·레거시 STATE 분포를 기록하고, 0x33 접근 차단을 값 거절과 별도 필드로 표시한다. 새로운 ECU 쓰기·키 전송은 추가하지 않는다.
