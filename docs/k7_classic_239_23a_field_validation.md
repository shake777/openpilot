# K7 classic `0x239·0x23A` 필드 검증. 2026-09-28

## 자료와 방법

- DAYOU 보고서 `1f4f1aca-5da3-5b67-a7d4-bfb736dd0989`의 원본 `20260927T235020Z-62fff1476ad040c9a6cacc06572fd0b5.c4radar`를 읽었다. 크기는 1,613,307바이트이고 SHA-256은 `5dadd884c3a347e460db06911f0398f92f6432dd25244370eb8bdd14660893bc`로 보고서와 일치한다.
- 버스 1의 `0x238~0x255`를 10개 슬롯 × 3개 주소로 정렬했다. 각 슬롯의 세 번째 주소가 들어온 시점에만 한 triplet을 집계해 이전 조각으로 인한 중복 방출을 제외했다.
- `c4scene` 432프레임과 시간 범위를 대조했다. 첨부 PDF는 UEX-1240 제품 사양으로, 이 차량의 CAN 필드 정의가 아니어서 근거로 사용하지 않았다.
- 차량 명령, 레이더 설정, 제어 코드 및 업로드 동작은 변경하지 않았다.

## 확인된 구조

| 항목 | 원본에서 확인한 결과 |
| --- | --- |
| `0x239·0x23A` 수신 | 슬롯 0에서 각각 1,454프레임. 약 33.3Hz. |
| 전체 triplet | 14,536개. 주소별 수신 순서로 별도 묶어 확인한 결과, 세 프레임의 rolling counter 불일치 0건, 150ms 초과 0건. |
| `0x239`의 4번째 바이트 bit 1 (`0x02`) | 슬롯 0에서 `0x238 status≠0`인 1,424건 모두 1이고 `status=0`인 30건 모두 0. 동일 위치의 모든 슬롯 합계도 `status≠0` 5,219/5,219건에서 1, `status=0` 0/9,317건에서 1. 이 캡처에서 상태 비트와 완전히 일치한다. |
| `0x23A`의 4번째 바이트 | 활성 상태가 연속된 슬롯 0 전환에서 값 증가가 `+1` 1,189건, `+2` 172건, `0` 60건이었다. 연속 빈 상태에서는 변화가 0인 경우가 28건이었다. 빈 상태에서 다시 활성으로 바뀔 때도 고정 시작값으로 재설정되지 않았다. |

`0x239`의 해당 비트는 이 자료에서 활성 상태를 가리키는 표지로 검증됐다. 그러나 첫 프레임의 상태값을 반복한 것일 수도 있으므로 독립적인 신뢰도, 객체 종류, 제어 사용 가능성을 뜻한다고 해석하지 않는다. `0x23A`의 진행 바이트는 고유 객체 ID가 아니라 sequence로만 보존한다.

## 아직 검증되지 않은 의미

- 나머지 가변 비트의 방향, 횡속도, 가속도, 품질, 물체 종류, 크기 의미는 확정하지 못했다. 가변 마스크나 활성·빈 슬롯 간 차이만으로는 물리적 의미를 증명할 수 없다.
- 첫 프레임의 횡위치 변화 방향과 후속 프레임 단일 비트의 관계를 전·후반으로 나눠 검사하려 했지만, 유효 횡이동 전환 657건 중 전반 635건, 후반 22건으로 편중됐다. 독립된 방향 검증 표본이 부족하다.
- `c4scene`에는 모델 선행차 확률 0.5 초과 303프레임, `lead_one.status` 참 243프레임이 있지만, raw radar points는 전 프레임 비어 있고 `lead_one.radar` 참도 0프레임이다. 객체별 독립 정답이나 영상이 없어 후속 비트에 객체 종류·품질 레이블을 붙일 수 없다.

## 적용 경계와 다음 검증

현재 확인값은 관찰·진단용이다. `0x239`의 상태 표지나 `0x23A` sequence를 `liveTracks`, 차간 제어, AEB 판단에 추가하지 않는다. 다른 시간대의 원본과 동기화된 영상 또는 독립 레이더 트랙을 확보해 활성 전환, 좌우 이동, 객체 교체가 실제 장면과 반복해서 맞는지 검증해야 한다.

분석 재현 스크립트는 로컬 `.analysis/archive/2026-09-28/k7-triplet-validation/analyze.py`에 보관한다. 기존 Hyundai classic 디코더와 제어 코드는 수정하지 않았다. Python 구문 검사와 실제 캡처 분석은 통과했다. 기존 pytest 테스트는 이 Windows Python 환경에 `capnp`와 `params_pyx`가 없어 수집되지 않았으며, 테스트 통과로 보고하지 않는다.
