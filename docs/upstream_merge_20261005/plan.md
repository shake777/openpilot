# 원 제작자 변경의 커스텀 브랜치 머지.

원 제작자 ajouatom/openpilot의 carrot-wip를 현재 carrot-wip-custom에 머지한다. 기존 커스텀 기능과 미추적 작업 자료를 보존하며 C4 기기 설치나 원격 푸시는 별도이다.

1. upstream 최신 리비전을 가져오고 차이를 확인한다.
2. 자동 커밋 없이 머지하여 충돌 여부와 변경 범위를 확인한다.
3. 변경된 영역의 가능한 테스트와 정적 검증을 실행한다.
4. 검증 결과와 한계를 기록하고 머지 커밋을 만든다.

## 원격 공개와 NAS 반영 추가 승인.

사용자가 원격 푸시와 NAS 반영을 승인했다. 현재 GitHub의 추가 커밋도 보존하여 병합하고 검증한 뒤 carrot-wip-custom에 푸시한다. 기존 Carrot Routes image 자동 경로로만 NAS를 업데이트하고 배포 커밋·updater 결과·실제 레이더 재계산을 확인한다. C4 기기 설치는 하지 않는다.

## 웹서버 배포 대상 확인.

사용자가 Docker 등이 설치된 웹서버를 지목했다. 해당 서버의 실행 서비스·컨테이너·업데이트 경로를 먼저 확인한다. NAS 저장소와 웹서버 분석 실행을 구분하고 실제 서비스가 확인되기 전에는 새 서버를 설치하거나 기존 서비스 설정을 바꾸지 않는다.
