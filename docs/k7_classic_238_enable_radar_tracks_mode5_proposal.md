# K7 0x238 레이더 트랙 설정값 5 적용안

작성일은 2026-09-28이다. 이 문서는 구현 제안이며, 설정값 `5`가 현재 차량이나 코드에서 동작한다는 뜻이 아니다. 현재 차량의 `EnableRadarTracks=0`은 그대로 유지한다.

## 요청과 결론

K7에서 이미 수신되는 `0x238–0x255` 객체를 종방향 선행차 입력으로 활용하되, 기본은 비활성으로 유지하고 CAN 체크 오류나 레이더 프로세스 오류를 만들지 않는 경로가 필요하다. 기존 설정의 `1` 이상을 모두 같은 의미로 바꾸는 것은 안전하지 않다. 기존 `1–3`은 레거시 `0x500` 트랙을 기대하며, 비-CAN FD 차량에서 레이더 ECU의 DID `0x0142` 설정 쓰기를 시도한다. `4`는 ECU 쓰기 없이 사전 활성화된 `0x500`을 관찰하는 모드다.

따라서 **K7 2020 전용 신규 값 `5`**를 제안한다. `0–4`와 음수 모드의 기존 의미는 유지한다. 값 `5`를 선택하더라도 별도의 검증이 끝나기 전에는 실제 주행·종방향 제어에 사용하지 않는다.

## 확인된 자료와 한계

- 제공된 약 43.6초 저속 캡처에서는 bus 1의 `0x238–0x255` 30개 주소가 약 33 Hz로 들어왔고, 완성된 14,536개 트리플렛의 롤링 카운터 불일치는 0건이었다.
- 거리 스케일과 대지 속도 해석은 거리 변화와 대체로 일치했다. `status=2`가 주된 활성 객체였지만, `status=1·6`의 정확한 의미와 횡위치 부호는 확인되지 않았다.
- 정지 구간에는 비전이 약 4.1 m 앞차를 보았지만 같은 거리의 레이더 객체는 없었다. 근거리 누락의 원인을 영상과 맞춰 확인해야 한다.
- 기존 `classicRadarTracks`는 표시용이고, `liveTracks`를 거쳐 선행차 선택에 들어가는 경로와 구분된다. 현재 개인 브랜치에는 별도 환경 변수로만 활성화되는 기본 비활성 후보 코드가 있으며, 설정값 `5`와는 아직 연결되지 않았다.

## 제안하는 값 `5`의 동작

1. 차종을 `KIA_K7_PE`로 한정한다. 다른 차종이 값 `5`를 갖더라도 레거시 설정값으로 해석하거나 ECU를 변경하지 않고 안전하게 기존 경로로 돌린다.
2. `0x7D0` 진단 세션 전환 및 DID `0x0142` 쓰기를 실행하지 않는다. 값 `5` 때문에 순정 SCC ECU를 추가로 끄거나 `openpilotLongitudinalControl`을 강제로 켜지 않는다. 기존에 사용 중인 알파 종방향 설정과 제어 권한을 그대로 따른다.
3. K7에서 없는 `0x500–0x53F` 메시지를 CAN 유효성의 필수 입력으로 등록하지 않는다. `0x238–0x255`의 bus 1 트리플렛만 해당 객체의 입력으로 사용한다.
4. 완성된 트리플렛, 일치하는 롤링 카운터, 신선한 `status=2`, 물리적으로 타당한 거리·횡위치의 연속 객체만 후보에 올린다. 기존 레이더 포인트가 있거나 입력 오류가 있으면 중복 추가하지 않는다. `status=1·6`은 해석 전까지 제외한다.
5. 잘못된 프레임이나 일시적인 수신 중단은 종방향 후보를 비우고 기존 비전 경로로 돌아가야 한다. 단순히 예외를 숨기거나 `radarState`를 유효한 것처럼 만드는 방식으로 CAN 체크 오류를 없애서는 안 된다.
6. `RadarTrackFlip` 적용과 NAS 재생에서도 같은 좌우 방향·객체 선택 결과가 나와야 한다. 순정 AEB 유지 여부는 CAN 수신만으로 증명하지 않으며 별도로 확인한다.

## 구현 및 통과 기준

- `EnableRadarTracks=0`의 레이더 파서, SCC, 안전 설정, 가감속 출력이 변경 전과 같아야 한다.
- `1–4`의 기존 동작을 유지한다. `5`에서는 K7의 ECU 설정 쓰기와 `0x500` 필수 파서가 실행되지 않아야 한다.
- 정상·누락·카운터 불일치·슬롯 재할당 자료에서 `radarcan`이 충돌하지 않고 오래된 객체를 제거해야 한다. 오류가 발생하면 유효한 선행차로 둔갑시키지 않아야 한다.
- 주차장 캡처뿐 아니라 직진 추종·끼어들기·정지·재출발 영상과 로그를 동기화해 횡위치 부호, 근거리 누락, 비전 대비 거리·속도, 잘못된 leadOne 선택을 오프라인으로 검증한다.
- 관련 테스트와 NAS Carrot Routes 재생을 같은 변경에 반영하고, 자동 빌드·서버 배포 커밋 및 실제 결과 페이지를 확인한다. 원제작자 저장소로는 푸시하지 않는다.
- 위 결과가 없으면 값 `5`를 사용자에게 켜도록 권하지 않는다. 현재의 `0`을 유지한다.

관련 구현은 `opendbc_repo/opendbc/car/hyundai/interface.py`, `opendbc_repo/opendbc/car/hyundai/radar_interface.py`, `openpilot/selfdrive/carrot/radar/radarcan.py`이다. 실제 설정 동작을 변경할 때는 한국어·영어 사용자 가이드와 설정 Wiki도 함께 갱신한다.
