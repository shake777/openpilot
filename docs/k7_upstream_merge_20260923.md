## Context Notes

머지 전 `HEAD=eec677a0`, 원본 `dc2d92ca`, 공통 조상 `daeda9d1`이다. 기존 미추적 파일은 사용자 자료이므로 보존한다. 원본 변경에는 CAN FD 정지 제어, 레거시 클러스터 표시, 레이더 방향·선행차 처리, 카메라 SCC 경고, CPU 배치와 설정 설명이 포함된다. 차량 실증 전까지 주행 개선을 주장하지 않는다.

설정 안내 충돌은 사용자 브랜치의 알파 종방향 토글 설명과 원본의 CAN FD 정지 제어 설명을 한국어·영어에서 모두 보존했다. 원본 레이더 replay 코드는 `carrot-wip` 전용 이미지 워크플로 대상으로, 사용자 브랜치 푸시만으로 NAS 재배포를 증명할 수 없다.

원본의 `Carrot Routes image` 실행 `35806679994`는 성공으로 확인했다. NAS 공유와 W 드라이브는 이 PC에서 연결되지 않아 NAS 업데이트 결과 및 실제 업로드 결과 페이지는 확인하지 못했다.
