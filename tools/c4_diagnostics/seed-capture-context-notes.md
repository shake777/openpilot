# 결정 기록

기록 범위는 security_exchanges의 단일 2701 요청과 UDS 반환 seed다. 전체 CAN 프레임 또는 전체 진단 순서 캡처는 아니다. 기존 부팅 자동 수집의 원문 비저장 정책은 유지한다. parked security probe만 원문을 기록하며 characterize 모드에는 seed 요청을 추가하지 않는다. Windows capnp 부재로 transport 통합 테스트는 검증하지 못했다.

사용자가 seed 원문 기록 및 업데이트를 승인했다. 기존 보고서는 길이만 기록하므로 원문 복원이 불가능하다. 원문은 기존 개인 진단 업로드 경로에만 기록하며 콘솔에는 출력하지 않는다. CAN 원시 프레임 캡처가 아니라 UDS 클라이언트가 반환한 payload 기록이다. 인증 키 전송·추정·설정 쓰기·새로운 부팅 자동 진단은 추가하지 않는다.
