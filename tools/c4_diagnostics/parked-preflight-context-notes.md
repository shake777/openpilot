# 주차 확인 개선 결정 기록

요약 개선 검증. unittest 44건 및 CLI 도움말·diff 검증 통과. --summarize-last는 저장 원본과 실행 시각을 유지하고 기존 status 스키마의 업로드 파일만 새로 만든다. 종료번호 0은 재요약 저장 성공이며 원 진단 성공이나 서버 수신 증명이 아니다. 실차 업데이트 및 실제 업로드 수신은 아직 미확인이다.

2026-09-23 후속. 사진에서 세션 비교 완료·설정 및 기본 세션 복귀가 확인됐다. 오류 21건은 모두 NRC 0x31이고 0140~0144는 unchanged다. 이 결과는 트랙 활성화 불가능의 증명이 아니다. 다음 분석에 필요한 원시 응답을 기존 보고서에서 요약한다. ECU 요청은 추가하지 않으며 기존 파일로 재요약·업로드 가능하게 한다. 가감속 문제는 이 진단 결과로 해결 판정하지 않는다.

deviceState를 poll 대상으로 사용해 고주기 carState만 수신하면서 재시도 횟수가 소진되는 것을 방지한다. 최대 10번의 수신 대기 후에도 조건이 충족되지 않으면 차단한다. 지연 수신·조건 거부·업로드 발견·서비스 비변경을 포함해 unittest 41건 통과. 실제 C4 실행과 서버 접수는 아직 확인하지 않았다.

2026-09-23. 사진에서 시작 전 주차 검증 차단이 확인됐다. 어떤 조건이 실패했는지는 기존 출력으로 알 수 없다. 수신 상태와 기어·속도·RPM·started 값을 보고하고 기존 조건은 유지한다. 준비가 늦으면 한정 대기한다. 차단도 기존 status 업로드 대상으로 저장하며 이 경우 comma 서비스를 재시작하지 않는다. 실제 ECU 활성화 및 가감속 제어는 이번 변경 범위가 아니다.
