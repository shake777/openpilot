# 주차 확인 개선 결정 기록

deviceState를 poll 대상으로 사용해 고주기 carState만 수신하면서 재시도 횟수가 소진되는 것을 방지한다. 최대 10번의 수신 대기 후에도 조건이 충족되지 않으면 차단한다. 지연 수신·조건 거부·업로드 발견·서비스 비변경을 포함해 unittest 41건 통과. 실제 C4 실행과 서버 접수는 아직 확인하지 않았다.

2026-09-23. 사진에서 시작 전 주차 검증 차단이 확인됐다. 어떤 조건이 실패했는지는 기존 출력으로 알 수 없다. 수신 상태와 기어·속도·RPM·started 값을 보고하고 기존 조건은 유지한다. 준비가 늦으면 한정 대기한다. 차단도 기존 status 업로드 대상으로 저장하며 이 경우 comma 서비스를 재시작하지 않는다. 실제 ECU 활성화 및 가감속 제어는 이번 변경 범위가 아니다.
