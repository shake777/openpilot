# C4 자동 읽기 전용 레이더 진단 계획.

차량 안에서 사용자 조작 없이, 신뢰할 수 있는 정차·제어 비활성 조건에서만 K7 레이더 식별정보와 DID 0142를 제한적으로 조회하고 결과를 기존 C4 서버로 전송한다.

1. 기존 CAN 송신과 안전 정책을 확인한다. 안전 모드 변경·우회는 금지한다.
2. 세션 변경, 설정 쓰기, 트랙 활성화 없이 F100 및 0142 읽기만 구현한다. 실패·미실행·응답 없음도 구분한다.
3. 실행 횟수와 시간을 제한하고 주행·제어 활성·상태 불명 시 중단한다.
4. 결과를 독립 파일로 보존하고 기존 인증·중복 방지 업로드 경로에 연결한다.
5. 조건 차단·ISO-TP·실패 기록·업로드를 모의시험한다. 실제 ECU 성공 여부는 다음 실차 결과로 확인한다.

기존 종방향/차종/레이더 트랙 설정은 변경하지 않는다. C4 전용 custom 브랜치 기능이며 공통 검출·선행차 선택 코드는 변경하지 않는다.
